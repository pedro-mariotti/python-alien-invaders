# Game2D_Alien
Projeto realizado em aula durante a disciplina AQS

Para criar o virtual environment
```bash
python -m venv .venv
```

Para definir execution policy
```bash
 Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser 
```
Para ativar o virtual environment
```bash
./.venv/Scripts/activate     
```
Para instalar o pygame
```bash
pip install pygame-ce  
```
Para rodar o jogo
```bash
python .src/alien_invasion.py
```
